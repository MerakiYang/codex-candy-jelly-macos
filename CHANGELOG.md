# Changelog · 更新记录

## 0.1.0 · 2026-10-20

Added light and dark native themes, clipboard helpers, a zero-dependency experimental macOS runtime launcher, reversible scoped styles, a local interactive preview, and nine protocol and renderer tests. Upstream SVG artwork remains MIT attributed.

新增浅色和深色原生主题、复制辅助脚本、无 npm 依赖的实验性 macOS 启动器、可恢复的作用域样式、本地交互预览及 9 项协议与渲染测试，保留上游 SVG 素材的 MIT 署名。
